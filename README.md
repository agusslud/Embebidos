Cada carpeta en la raíz corresponde a un TP y contiene el proyecto de CubeMX completo (código generado + `.ioc`).

## Cómo abrir un proyecto

1. Clonar el repo
2. Abrir STM32CubeIDE → File → Open Projects from File System
3. Seleccionar la carpeta del TP correspondiente (ej. `Tp1_Discovery/`)
4. Si falta el `.project`/`.cproject`, regenerar el código desde el `.ioc` con CubeMX antes de compilar
